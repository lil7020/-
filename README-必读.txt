二、三种启动方式（任选一种）
==============================================================================

【方式1】一键启动（最推荐！）
------------------------------------------------------------------------------
    1. 找到文件：启动-双击我.bat
    2. 双击它！
    3. 等待浏览器自动打开
    4. 看到登录界面就成功了！


【方式2】使用 Node.js（如果已安装）
------------------------------------------------------------------------------
    1. 在当前文件夹，按住Shift键 + 右键
    2. 选择"在此处打开PowerShell窗口"或"在终端中打开"
    3. 输入：node server-simple.js
    4. 看到"Server started successfully"后
    5. 浏览器访问：http://localhost:3000/


【方式3】直接打开（最简单，但功能可能受限）
------------------------------------------------------------------------------
    1. 直接双击 index.html 文件
    2. 用浏览器打开
    3. ⚠️  注意：某些功能可能不完整，建议用方式1或2

四、常见问题
==============================================================================

Q: 显示"服务不可用"？
A: 检查是否启动了服务器，确保访问的是 http://localhost:3000/ 而不是 file://...

Q: 端口被占用？
A: 打开任务管理器，结束可能占用3000端口的程序，或重启电脑

Q: 无法登录？
A: 确认账号密码正确，注意大小写
