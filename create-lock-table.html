🔐 创建上传锁表

此工具将帮助您在 Supabase 中创建上传锁表，用于防止多人同时上传数据导致冲突。

操作步骤：
1. 复制下方的 SQL 代码
2. 登录 Supabase 后台
3. 进入您的项目 → 点击左侧 "SQL Editor"
4. 粘贴代码并点击 "RUN"
-- 创建上传锁表 CREATE TABLE sync_lock ( id TEXT PRIMARY KEY, username TEXT NOT NULL, lock_time TIMESTAMP NOT NULL DEFAULT NOW() ); -- 添加行级安全策略（允许所有用户访问） ALTER TABLE sync_lock ENABLE ROW LEVEL SECURITY; CREATE POLICY "Allow all users to access sync_lock" ON sync_lock FOR ALL USING (true); -- 创建索引（可选） CREATE INDEX IF NOT EXISTS idx_sync_lock_id ON sync_lock(id);
